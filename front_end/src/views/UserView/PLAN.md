# 个人主页概览与录像页重构计划

制定日期：2026-10-16。状态：主体业务实现、rank 分段配色及相关测试用例已更新，待浏览器及完整工作流验收。下文保留设计约定与实施前核查依据。

## 1. 目标与范围

将个人主页默认入口改为轻量的 PB 纪录概览，避免访问 `summary` 就下载、构造和分析全部录像。日历、BV 表和散点图统一归入录像 tab：上方切换日历/BV 概览，下方在录像表格和散点图之间切换。表格与散点图是同一份数据的两种展示方式，散点图作为正式功能开放。

本次保留个人主页现有路由、账号关联、纪录、上传和设置功能，以及普通用户与本人可见录像的权限差异。不改 PB 排名规则，不将完整录像列表改成服务端分页；录像 tab 首次进入仍需要一次获取当前权限下的全部录像。本次优化首先消除概览入口的重请求，并避免同一区域的多种展示同时挂载。

### 页面结构

```text
概览 /player/:id/summary
  紧凑控件：普通 / NF、time / bvs / stnb / rank、刷新
  初级 PB 网格（每行 10 格）
  中级 PB 网格（每行 10 格）
  高级 PB 网格（每行 10 格）

录像 /player/:id/videos
  上方紧凑控件：不显示 / 日历图 / BV 表
  当前选中的一个概览可视化（不显示时整个区域收起）
  当前选择范围、范围内录像数量、清除选择
  下方紧凑控件：表格 / 散点图、共享筛选及对应展示设置
  表格（本地分页、排序）或散点图，共用筛选后的录像数据
```

默认进入录像 tab 时，上方不显示可视化，下方显示表格，数据为全部可见录像。首次切到日历或 BV 表、尚未选择日期/格子时，下方仍使用全部录像；下方选择散点图后，日期/BV 选择照样生效。

### 已确认的产品口径（2026-10-16）

| 项目 | 确认方案 |
| --- | --- |
| PB 指标 | 紧凑按钮组单选 `time / bvs / stnb / rank`，默认 `time`，高亮当前指标；支持普通/NF 切换，默认普通榜 |
| 录像页初始状态 | 上方不显示图表，下方显示表格 |
| 上下方筛选关系 | 下方共享筛选只影响表格和散点图，上方日历/BV 表保留完整分布 |
| BV 表自身的筛选 | 仅影响格子的代表录像、数值等展示，不传递给下方表格或散点图，也不缩窄选中桶的录像成员 |
| BV 格子点击 | 录像页固定为选择联动：选中 `(level, bv)` 后下方使用该桶全部录像，再应用下方自己的共享筛选；桶内包括所有模式、状态和软件。不提供点击模式切换 |
| 旧 BV 点击模式 | 删除“展示录像列表”的全局弹窗模式及其切换控件；其他不启用选择联动的调用方保留直接预览代表录像 |
| 散点图入口 | 正式功能，不受实验开关限制，与下方表格互相切换 |
| 取消选择 | 再点同一日期/格子或点击清除可取消；切换上方概览时清除，切换下方展示时保留 |

## 3. 概览页：PB 纪录网格

### 3.1 数据与展示

- 在 `pbRankingService.ts` 增加 `PBPlayerRecord` 类型和 `fetchPBPlayerRecords(playerId)`，对接现有玩家 PB 接口。页面首次进入仅获取个人资料、PB 纪录及必要的轻量资格信息，不请求 `/api/userprofile/videolist`。
- 三个等级沿用现有 BV 网格的十列排列、个位列头和十位行标。显示区间依据该等级已有 PB 的最小/最大 BV 按十位补齐，中间没有纪录的格子留空；整级别没有纪录时显示空态，不展开大量空格。
- 数据按 `(nf, level, bv)` 建立索引。默认普通榜，可切换 NF；普通 PB 榜包括 NF 录像，NF 榜依据既有后端规则，不能用旧 NF mode 编码代替。
- 指标支持单选显示 `time`、`bvs`、`stnb`、`rank`，默认 `time`。指标和普通/NF 切换全部使用已加载的响应，不逐格或逐榜请求，也不加载完整录像。
- `time`、`bvs`、`stnb` 使用同一条 PB 录像及 `formatPBValue` 计算和格式化；切换指标不会改成“按该指标重新选另一条录像”。不得从完整录像列表重新推算 PB 或排名。
- `rank` 使用接口缓存值，按 1 起算；`rank === null` 显示 `--`，保留已有纪录，不能显示为 0、误当无纪录，或临时逐桶请求排名。
- 无纪录的格子无预览操作；有纪录的格子通过已有 `VideoPreviewLink` 使用 `video_id` 预览。简单文本提示使用原生 `title`，以换行符分行展示响应已有字段及可推导指标，不为每格预取录像详情。
- 时间/Bvs/STNB 颜色复用现有分段主题；`rank` 使用下述独立的名次配色。保持浅色、深色及横向滚动能力。

### 3.2 组件边界

新增页面专用 `PBRecordGrid.vue`（可置于 `UserView` 下），接收 PB 纪录、等级、榜别和展示指标。复用 BV 网格的行列标、范围计算及已有基础样式；若确有重复，只提取一个窄职责的网格布局/插槽外壳。

不要把 PB 响应伪装成字段缺失的 `VideoAbstract`，也不要让已有 `BBBvSummary.Cell` 同时承担 PB 排名和全录像聚合两类数据协议。已有 `visualization/VideoCell.vue` 可复用数值着色能力，但它的完整录像 Tooltip 不能通过伪造录像对象启用。

### 3.3 rank 配色

按绝对名次分段，复用已有 `rank` 数据，不增加请求。深浅主题共用一套基色：前三名直接使用不透明的金、银、铜；后续蓝色通过背景色的 alpha 与当前底色混合，自动呈现浅色底上的淡色、深色底上的暗色。

| 排名 | 基色 | 初始 alpha（不透明度） |
| --- | --- | --- |
| 1 | 金色 `#FFC000` | 100%，直接使用不透明颜色 |
| 2 | 银色 `#A0A0A0` | 100%，直接使用不透明颜色 |
| 3 | 铜色 `#CD7F32` | 100%，直接使用不透明颜色 |
| 4–10 | 蓝色 `#409EFF` | 22% |
| 11–50 | 同一蓝色 `#409EFF` | 14% |
| 51–100 | 同一蓝色 `#409EFF` | 7% |
| 101 及以后 | 无背景填色 | 0% |
| 排名缺失 `--` | 无背景填色 | 0% |

前三名使用不透明背景和固定深色文字 `#141414`，保证在两种主题下均清晰。后续蓝色使用 `background-color: rgb(R G B / alpha)`，文字保持 `var(--ui-text-color-regular)`；所有数字和链接完全不透明。不设置整个格子的 `opacity`。蓝色初始方案深浅主题使用相同 alpha；若浏览器验收中深色仍偏亮，仅覆盖深色主题的 alpha，保留共用基色。无纪录空格保持空白。

复用 `PiecewiseColorScheme.getColor` 的分段选色。当前 `getStyle` 根据未与底色混合的颜色推断文字颜色，不直接用于 rank；rank 分别指定奖牌深色文字和后续主题文字色，无需修改公共配色工具。

## 4. 录像页：上方概览与下方展示联动

### 4.1 单一数据源与选择状态

录像页负责一个完整数据源 `allVideos`，即当前访问者有权看到的该玩家录像。上方日历/BV 表始终使用完整数据源；日期/BV 选择先推导出 `selectedVideos`，共享的软件、状态、等级、模式等筛选再推导出 `filteredVideos`。下方表格和散点图都使用同一个 `filteredVideos`，不各自维护一份筛选数据。不能把已经筛过的数据传回上方概览，造成选中后其他格子消失或日期范围缩小。

```text
allVideos ──→ 上方日历 / BV 表
    └── 日期 / BV 选择 ──→ selectedVideos
                              └── 共享筛选 ──→ filteredVideos
                                                  ├── 表格：排序、分页
                                                  └── 散点图：全部筛选结果
```

页面维护三类独立状态：

```ts
type OverviewVisualization = 'none' | 'calendar' | 'bv';
type VideoPresentation = 'table' | 'scatter';
type VideoSelection =
    | { kind: 'all' }
    | { kind: 'date'; dateKey: string }
    | { kind: 'bv'; level: 'b' | 'i' | 'e'; bv: number };
```

选择状态保存稳定的日期/BV 键，不保存一份可能过期的录像数组。刷新数据后重新推导对应录像，BV 分组不再存在时清除选择；日历允许选择无录像日期，仍保留该日期及空态。当前页面内切换 tab 可保留选择；跨用户或登录身份变化时必须重置。首轮不把具体日期/BV 选择持久化到全局 localStorage。

| 操作或状态 | 下方表格/散点图的数据范围（应用共享筛选前） | 高亮 |
| --- | --- | --- |
| 不显示可视化 | `allVideos` | 无 |
| 显示日历/BV 表但未选择 | `allVideos` | 无 |
| 点击日期 | 该日期分组的全部录像 | 仅该日期边框高亮 |
| 点击 `(level, bv)` 格子 | 该等级、BV 分组的全部录像 | 仅该格边框高亮 |
| 再次点击同一选中项、点击“清除选择” | `allVideos` | 清除 |
| 切换上方概览或收起概览 | 清除旧图表选择，恢复 `allVideos` | 清除 |
| 更换查看玩家 | 新玩家的数据加载完成后显示其全集 | 清除 |
| 下方切换表格/散点图 | 数据范围及共享筛选不变 | 保留上方日期/BV 高亮 |

这里的“全部录像”始终受后端可见性约束。已有软件、状态、等级、模式等显式筛选语义保留，并成为表格/散点图的共享状态；两种展示下均可查看和修改这些筛选，不能只藏在表格表头中。复用现有筛选能力，必要时为 `VideoList` 增加可选的受控筛选接口，不另建通用筛选引擎，也不让两套独立逻辑产生不同结果。

表格页码和显示顺序属于展示状态，不截断散点图数据：即使表格只显示一页，散点图仍接收全部 `filteredVideos`。范围或共享筛选变化时重置表格到第一页；仅切换表格/散点图时保留有效页码、列配置、排序和散点图配置，不清空选择或重新请求录像。当前范围计数与共享筛选后计数应可区分。

### 4.2 日历

- 为 `ActivityCalendarAbstract` 增加可选的 `selectable`、`selectedDateKey` 和日期选择事件；未启用时保留其他调用方原行为。
- 直接使用现有 `groupVideosByDate` 生成的分组。默认按上传日期；启用结束日期时沿用 `end_time ?? upload_time` 的回退规则。日期键使用现有 `toISODateString` 的浏览器本地年月日，不能改用 `toISOString().slice(0, 10)` 导致跨时区偏移。
- 切换日期来源时清除当前日期选择；无结束时间、跨午夜及时区边界的录像在图表计数和列表中必须落入同一分组。
- 日期单元格可通过鼠标及 Enter/Space 选择；用 `aria-pressed` 表达选中状态。允许选择空日期，列表明确显示该日无录像。
- 选中边框使用主题主色，深浅主题均可辨识，不改变原有日期尺寸、饼图数据或挤动相邻日期。区分持续的选中边框与键盘焦点指示。
- 保留既有统计条、月份/星期标签和 Tooltip。统计条描述完整数据，范围提示描述当前选择，避免混淆两个计数。

### 4.3 BV 表

- 为 `BBBvSummary` 增加由调用方指定的 `selectable`、受控选中 BV 和选择事件，由录像页保存完整 `(level, bv)`，避免不同等级的同一 BV 同时高亮。录像页始终启用选择联动，不向用户提供点击模式选择器。
- 复用 `groupVideosByBBBv`：成员范围是该等级和该 BV 的全部录像，不只取格子里展示的最佳录像，也不隐式限定为正式成绩、某一模式或 PB 合格录像。
- 原有模板、代表录像排序、软件筛选、图标和“新纪录”提示继续控制格子的展示。软件筛选不能在点击时悄悄丢弃该桶其他录像；下方显式软件筛选统一作用于表格和散点图。
- BV 表自身的软件等筛选与下方共享筛选独立：修改它们只重新选择格子里的代表录像/展示数值，不改变 `selectedVideos`、`filteredVideos` 或下方筛选状态。下方筛选也不反向改变 BV 格子的完整数据分组。
- 例如 BV 表只展示 AVF 的代表成绩，点击高级 BV=100 的格子后，下方仍包含该桶内的 AVF、RMV 等全部录像；只有下方自己的软件筛选才能进一步限制这些成员。
- 实际没有录像的补位格不触发选择；存在录像但当前代表录像筛选没有结果时，不把原始桶误判为空桶。选中状态以原始分组为准。
- 删除原有 `fast/advanced` 切换控件、“展示录像列表”的处理分支及 `BBBvSummaryConfig.tooltipMode` 配置，不以新增模式选择器替代它；清理对应文案和过时测试。旧 localStorage 中残留的该字段不再参与行为判断，其他展示设置继续保留。
- 录像页选择模式下，单击主要格子操作更新下方表格/散点图，不同时打开预览或 `store.video_list_show` 全局弹窗。录像预览通过独立操作/下方列表保留，避免按钮嵌套和事件冒泡造成双重动作；其他未启用 `selectable` 的调用方直接预览代表录像。选择联动与直接预览由调用场景决定，不由用户切换。
- 移除 BV 格子打开全局列表的入口时，先核查 `store.video_list_show` 和全局列表弹窗的其他调用方；仍有其他用途时保留其状态和弹窗，不顺带删除独立入口。
- 键盘及选中边框约束与日历一致。切换显示指标不清除已选 `(level, bv)`。

### 4.4 下方表格与散点图切换

- 散点图从概览移出，与录像表格并列，作为下方展示模式；它不属于上方“不显示/日历/BV”的切换器。上方选中日历时，下方可以显示表格，也可以显示散点图；BV 表同理。
- 表格与散点图互斥展示，共享 `filteredVideos`；切换只改变展示方式，不复制、重新获取录像，也不丢失上方选择和共享筛选。
- 不把散点图输入限制成 DataTable 当前页数据。表格分页、排序不改变散点图的录像成员；日期/BV 选择和共享筛选则同时改变两种展示的数据范围。
- 保留现有散点图的轴、着色、Tooltip 等能力。本轮不增加通过散点框选反向修改上方日期/BV 选择的功能。
- 散点图为正式功能，所有可访问该录像页的用户均可切换使用，不依赖实验开关。移除迁移后入口的 `v-experimental` 限制，保留其他功能的实验开关行为。
- 不同时挂载两份昂贵的下方展示，必要的展示设置由父级保存以便恢复。

## 5. 请求生命周期、缓存与失效

### 5.1 只在需要的页面加载全量录像

- 从 `UserSummaryView` 移除 `fetchUserVideos`、全录像组件和相应 watcher。
- 录像 tab 激活且缺少有效数据时才请求全量录像；同一用户切换上方概览或下方表格/散点图均不发请求，来回切 tab 复用当前有效数据。提供显式刷新入口。
- 复用 `userService.ts` 已有的同用户并发请求合并；它只有 pending Promise 去重，不是结果缓存，不能把它当成已解决跨 tab 重复下载。
- 完整结果及失效状态保留在现有用户数据/页面状态中，不再维护第二份完整录像副本，不持久化到用户资料 IndexedDB。
- 必须显式处理 `keep-alive` 的激活/停用和路由用户 ID。已缓存的录像页处于后台时，不因 `store.player` 更新就下载另一个玩家全部录像。
- 用请求序号或 watcher cleanup 防止 A 玩家慢响应写入 B 玩家；旧请求的 `finally` 也不能清除新请求的 loading。不能仅用单个 `if (loading) return` 跳过用户切换后的必要加载。
- 加载中隐藏旧玩家结果，区分加载、成功空集和失败；失败有重试操作，loading 必须在成功/失败后正常结束。失活页的响应可以填充其仍有效的缓存，但不能覆盖当前玩家 UI。

### 5.2 与登录身份和业务更新同步

- 全量录像缓存有效性至少区分目标玩家与访问身份。退出登录、切换账号或由本人视图转为访客视图时，不能继续显示先前缓存的未公开比赛录像。
- 上传、绑定/解绑标识等改变录像或正式状态的操作，标记录像和 PB 视图过期；页面下次激活时按需刷新，不在设置页立即后台下载全量录像。
- 本人公开比赛录像后沿用现有 `revealUserVideo`，成功才修改该录像的公开标记，保留失败处理和确认弹窗。仅修改公开状态时可原地更新；如影响 PB 收录，再使 PB 数据失效。
- 范围筛选与可视化切换本身不触发上传、公开、缓存重建或排名维护。

### 5.3 头像/签名资格不能依赖全量录像

这是本次性能改动必须一并解除的依赖，而非新增解锁规则。

- 当前前端 `store.expTimeMs` 扫描 `store.user.videos`；直接移除录像加载会让未访问过录像 tab 的合格玩家无法修改头像/签名。
- 后端 `userprofile.services.has_sub200_expert_video` 已按扫雷网普通榜的 `et` 判断资格，包含其 3BV 门槛；PB 桶的最短时间与该口径不等价，不能用 PB 网格的最小值替代。
- 优先复用 `fetchSaoleiRecords` / `GET /api/speedranking/player/{id}` 读取登录本人 `saolei.et`，驱动头像及签名资格；按登录身份管理轻量数据与加载状态，并与纪录页共享请求/缓存。
- 资格未知、失败和未达标分别处理，查询失败保留重试，不伪装成已确认未达标；现有次数、冷却和后端最终校验继续生效。
- 删除设置页首次进入时为资格判断而执行的全录像加载。标识变更仅刷新必要的轻量纪录并使录像缓存过期；设置页不主动为此拉取全部录像。

## 7. 测试与验收

### 自动化重点

1. **请求边界**：直接访问 summary、从其他 tab 返回 summary、访问本人/他人概览，都不请求 `videolist`；切换 PB 指标和普通/NF 不追加请求。录像 tab 首次激活加载一次，切换上方概览或下方表格/散点图不重复加载。
2. **PB 网格**：覆盖已知时间推导指标、普通/NF 数据分离、缺失纪录、`rank=null`、录像链接及空态/失败重试；复用现有 PB 格式化单元测试，不复制公式写镜像测试。
3. **范围联动**：使用固定录像集合覆盖同日跨等级、自定义等级、跨午夜、缺失结束时间、同 BV 跨等级/模式/软件。选择范围并应用共享筛选后，表格分页前数据与散点图输入的录像 ID 集合相同；下方切换保留日期/BV 高亮和筛选，上方切换/清除恢复全集。覆盖结果超过一页时散点图仍收到全部筛选结果，以及筛选变化后表格回到第一页。
4. **交互**：选中边框在浅/深主题可辨；Enter/Space 选择有效；录像页主要格子操作只更新选择，不同时打开播放器/全局列表弹窗。无旧点击模式切换控件；非选择调用方直接预览代表录像，旧 `tooltipMode=advanced` 设置不再触发列表弹窗。图表 Tooltip 和独立预览继续可用。
5. **异步与权限**：A→B 快速切换、请求乱序、失活页、重复激活、退出登录、公开录像失败与成功，均不串用户、不泄漏隐藏录像、不遗留 loading。
6. **业务失效**：上传或标识变更后下次访问按需更新；设置页直接访问且未加载录像时，头像/签名资格与后端扫雷网 `et` 一致。
7. **筛选隔离**：BV 表设置为只展示某种软件时，选中桶传给下方的原始录像成员保持完整；修改 BV 展示筛选不改变下方数据，修改下方共享筛选不改变上方分布。
8. **正式散点图**：关闭全局实验开关时，仍可切换表格/散点图，使用相同数据且保留选择；其他实验功能不因该改动自动开放。

更新现有 `UserVideoView.cy.ts`、`UserView/App.cy.ts`、日历/BV 组件测试和相关 service 单元测试；为新的 PB 概览补充必要的组件覆盖。`cypress/e2e/profile.cy.ts` 中“summary 自动加载所有录像/日历/BV”的旧预期必须迁到录像 tab，并增加概览无全量请求的验证。断言等待请求或业务就绪状态，不使用固定 sleep。

### 人工验收场景

- 小数据和大数据用户均可先看到轻量 PB 概览；Network 中没有全量录像请求。无 PB 纪录不等于请求失败。
- 直接进入录像 tab，上方隐藏/日历/BV 的三种状态与下方表格/散点图独立切换，支持日历+散点图、BV 表+散点图等组合；未开启实验功能时散点图也正常可用。
