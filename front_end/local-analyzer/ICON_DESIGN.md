# Analyzer 图标设计

当前方向：独立设计 Analyzer 主图标，网站标志作为右下角归属角标。

- 图标源文件：[video-analyzer.svg](../src/assets/video-analyzer.svg)。主图标以经典浅灰凸起边框的扫雷格子为背景，内部两根左高右低的柱形表达分析数据，右侧红旗直接插在横轴上。
- 网站角标：右下角直接内嵌用户提供的 `src/assets/logo.svg` 原始矢量路径，保持原六边形、双色齿轮、中心电路、颜色和透明背景，表达开源扫雷网归属；更新网站 SVG 时需同步更新此角标。
- 旗子风格：旗面恢复红色 `#e53935`，轮廓、旗杆与横轴同为深蓝色 `#171e60`；保留旗面圆角连接和旗杆圆润端点。
- 视觉层级：保留 96px 凸起边框，图表连同描边及横轴均限制在内框 128–864 范围。左柱加高到 624px，中间柱保留 352px，等宽 216px，原右柱删除。旗杆保持 x=748、顶端 y=192，底部延伸到横轴 y=852；旗面高度及左尖端 x=430 保留，右端路径到 x=736，补偿 16px 描边的一半，使可见红色填充右边缘 x=728 正好接到旗杆左边缘。网站角标从 448px 缩小四分之一柱宽（54px）到 394px（画布宽约 38%），位于右下角 x=y=620，叠在图表及部分旗杆前作为归属标识。柱形沿用蓝色系，与网站配色关联。
- [尺寸与主题预览](./ICON_PREVIEW.html)：双击 HTML 查看浅色/深色背景上的 256、64、32、24、16px 图标，并与网站原标志对照。预览依赖仓库内的相对路径，不属于离线发布包。
- 主图形与网站角标均为纯矢量，图标不包含 PNG 或外部资源；网站原 SVG 补充与其 613×613 画布一致的 viewBox，以便正确缩放。小尺寸的图形辨识度与角标细节，以浏览器实际预览为准。

图标已用于网站软件下载弹窗的 Analyzer 标签页、录像页的离线包下载按钮，以及离线页面的信息区和 favicon。离线入口使用内联 SVG 数据 URL，打包脚本检查 favicon 已内联，保证图标在 file:// 下不依赖外部资源。接入离线产物时按 [版本管理约束](./VERSIONING.md) 更新版本及变更记录；以后修改本图标也会影响离线包，需要按约束管理版本。
