解压后双击 index.html，用 Chrome 或 Edge 打开。选择或拖入一份 EVF/AVF/MVF/RMV 录像。
Extract the ZIP, open index.html in Chrome or Edge, then choose or drop one EVF/AVF/MVF/RMV replay.

信息区域的 English / 中文 按钮可切换界面语言，下次打开时保留选择。
Use the English / 中文 button in the info area to switch the interface language; your choice is saved for the next visit.

无需本地服务器或网络连接。视频导出取决于浏览器编码器支持；剪贴板操作可能需要浏览器许可。
No local server or network connection is required. Video export depends on browser codecs; clipboard access may require browser permission.

表达式帮助位于 help/guide/replay-expressions.html（中文）及 help/en/guide/replay-expressions.html（English）。
