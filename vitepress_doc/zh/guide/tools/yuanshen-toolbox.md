# 元神工具箱

元神工具箱是一个 Windows 桌面工具，在本地读取元扫雷（`.evf`）与阿比特（`.avf`）录像。

作者是本站玩家（扫雷网 #27415、开源扫雷网 #3）。**这是第三方工具，与开源扫雷网、元扫雷、阿比特均无隶属关系**：它只读本地录像，只调用本站的公开接口，不上传录像之外的任何数据。

## 能做什么

向开源扫雷网上传本地 PB 和前端成绩。

其他功能正在更新中，欢迎提建议。

## 下载

到 [Releases](https://github.com/Corday-nkusky/yuanshen-toolbox/releases/latest) 下载最新的 `YuanshenToolbox.exe`（单文件，约 27 MB）。免安装，不需要 Python，双击即用。

> GitHub 的附件名不支持中文，所以文件名是 `YuanshenToolbox.exe`；下载后可以随意改名，不影响功能。

## 使用方法

1. **放**：把 exe 放到元扫雷的 `Metasweeper<版本号>` 目录里，也就是 `replay` 目录的上一级。不知道 `replay` 在哪的话，打开元扫雷菜单「查看 → 录像目录」（快捷键 `W`），返回上一级就是。
2. **运行**：双击运行。程序优先读取 exe 旁边的 `replay`；找不到时会搜索 `%APPDATA%`、`%LOCALAPPDATA%` 下的所有 `Metasweeper*`；都没有才让你手动选择目录。选一次就记住。
3. **等首次扫描**：第一次扫描要逐局重演录像，两万局约 3 分钟，底部有进度条和剩余时间；之后走缓存，一秒级完成。
4. **看结果**：页签切换「概览 / PB 表 / 前端成绩 / 上传」。点表头排序，双击某行复制该录像的完整路径。
5. **上传**（可选）：在「上传」页点「登录…」，输本站账号、密码与验证码，勾上「保持登录 90 天」登录一次，之后靠保存的会话 Cookie，不必再输密码。选好范围后点「上传全部未传」，上传前会弹确认框，列出这一批的级别、风格、时间和大小。

阿比特的录像目录**不会自动加入**：要加就在「路径 (N)…」里手动添加，请确认路径里都是你自己的且接受上传到开源扫雷网的录像。

## 数据存在哪

运行期产生的东西都在 exe 同目录的 `元神工具箱-data\` 里：界面配置、加密保存的账号、上传台账、扫描缓存、日志。删掉这个文件夹即回到全新状态。exe 放在不可写的位置（如 `C:\Program Files`）时，自动回落到 `%APPDATA%\元神工具箱\`。

账号密码与会话 Cookie 用 Windows DPAPI 加密落盘，绑定当前 Windows 用户与本机，换一台机器解不开，文件里也没有明文。日志不含密码、验证码和 Cookie。

## 常见问题

| 情况                 | 处理                                           |
| ------------------ | -------------------------------------------- |
| 成绩算错了，或刚打了新局       | 点「重新扫描」；仍然不对就在「诊断…」里清空扫描缓存后重扫                |
| 上传后网站上显示 `d`（标识不符） | 录像标识与账号里登记的不一致，按[扫雷标识](../identifier.md)改对再传 |
| 上传中途停了             | 已成功的不受影响，恢复后点「重试失败」只补传剩下的                    |
| 想报问题               | 「诊断…」→「导出诊断包…」，生成的 zip 含系统信息、配置和日志，不含凭据密文    |
