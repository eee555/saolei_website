# 账号关联

账号关联用于把你在不同平台的身份关联到本站账号，你可以借助这个功能在不同平台上认识更多朋友。账号关联功能在个人主页的《账号关联》选项卡中。

你需要先登录才能操作自己的账号关联。

## 关联流程

Mineracer 通过站外确认自动完成关联，其他平台需要填写 ID 并由管理员认证。

### Mineracer

1. 在自己的《账号关联》选项卡中，找到 Mineracer 区域，点击《生成关联链接》。无需手动填写 Mineracer 用户 ID。
2. 点击《打开链接》，在新窗口中登录你要关联的 Mineracer 账号，并确认关联。确认前请检查登录的账号是否正确。
3. 手动切回开源扫雷网的账号关联页。Mineracer 不会自动跳转回本站；本站会自动检查确认结果，也可以点击《刷新状态》。
4. 关联成功后，页面会显示 Mineracer 用户 ID 和绑定更新时间，无需管理员审核。

关联链接有效期为 10 分钟，页面会显示剩余时间。如果链接过期，点击《重新生成链接》后再次打开并确认。不想继续时，可以不确认，让链接自然过期。

::: warning 关联前请确认账号
每个开源扫雷网账号只能关联一个 Mineracer 账号，同一个 Mineracer 账号也不能关联多个开源扫雷网账号。Mineracer 目前不支持解绑，本站也不提供解绑或更换 Mineracer 账号的功能。
:::

### 其他平台

1. 在账号关联的界面中，如果你还有未关联的其他平台，可以看到一个加号按钮，点击该按钮会显示一个弹窗引导你进行账号关联。
2. 输入平台和id后，为了防止冒领他人账号，你需要取得管理员的信任，让管理员认证该账号。

### 关于id
“id”这个词存在一定歧义，在部分网站有可能理解为用户名或昵称。对于需要手动填写 ID 的平台，id应当是一串数字。你选择账号所在的平台后，下方应当会加载出寻找对应平台的id的方法。Mineracer 的用户 ID 由授权流程自动获取，不适用这里的填写要求。

一旦确认关联，操作不可撤销（请参与代码贡献，帮我们解决这个问题），因此请谨慎填写id。如果确实填错了id，请联系管理员处理。

### 取得管理员信任
管理员后台可以看到你的关联请求。如果他们认识你，会直接进行认证，否则需要你联系他们。

扫雷网、Minesweeper.Online、哔哩哔哩、腾讯QQ都支持私信，直接在这些平台私信管理员账号，告诉管理员你的开源扫雷网id，只要信息一致，管理员应当认证该账号。国际网支持你关联扫雷网和Minesweeper.Online账号，如果这些账号和你在开源扫雷网上关联的一致，管理员应当认证你的国际网账号。

## 隐私相关
开源扫雷网是实名制的，所以一旦关联了其他平台的账号，意味着该平台上其他用户可以知晓你的实名。有的平台账号关联仅用于客服支持，那么该账号是私密的，只对于管理员可见。目前腾讯QQ是私密平台。

## 常见问题
### 为什么显示“账号未绑定”？
对于手动填写 ID 的平台，为了防止账号冒领，账号关联由管理员人工审核确认。你需要加群联系管理员，如果管理员认识你，确认你就是账号拥有者，会直接审核确认。如果管理员无法确认你的身份，你还需要在对应的平台上联系管理员在该平台的账号（你可以通过管理员主页的“账号关联”选项卡找到该信息）。Mineracer 无需人工审核，在 Mineracer 确认后即可自动完成关联。

### Mineracer 一直显示“等待 Mineracer 确认”，怎么办？
请确认你已经打开生成的链接，并在 Mineracer 完成确认，然后返回本站等待状态更新，或点击《刷新状态》。仅生成或打开链接不会完成关联。如果链接已过期，请重新生成链接。

### Mineracer 提示账号已被其他用户绑定，怎么办？
同一个 Mineracer 账号只能关联一个开源扫雷网账号。请检查当前登录的两个平台账号是否正确，不能将已关联的 Mineracer 账号重复绑定到另一个本站账号。目前也不支持通过解绑来转移关联。

### 我关联的时候填错了id，怎么办？
目前网站不支持直接修改id，请联系管理员进行处理。

### 为什么自媒体平台不是私密平台？
我们即将开发创作推广功能，这个功能允许你在开源扫雷网推广你在自媒体平台上的扫雷作品。从你推广你的作品开始，你在该自媒体平台上的账号已经暴露了。如果你不需要推广你的作品，就没有必要，而且我们也不建议关联自媒体账号。

### 如何撤销关联？
Mineracer 目前不支持解绑或更换关联账号，管理员也无法通过本站的账号关联功能解除绑定。其他平台目前不支持自行撤销关联，请联系管理员进行处理。
